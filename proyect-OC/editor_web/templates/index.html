      Guía rápida del editor
      
        
      
          
      
            Este simulador te deja escribir microoperaciones (pasos que mueven datos entre registros, memoria y la ALU) y ver la traza al costado mientras editás.
          
      
          
      El editor de código
      
          
      
            Escribí una microoperación por línea. Podés usar comentarios al final de línea con ;, // o #.
          
      
          
      Qué significa la flecha ->
      
          
      
            La flecha es una asignación: lo que está a la derecha queda con el resultado de lo que está a la izquierda (como en muchos apuntes de organización de computadoras).
          
      
          
      ACC+1 -> ACC     ; incrementa el acumulador
GPR -> ACC       ; copia GPR al acumulador
PC -> MAR        ; dirección de instrucción a MAR
      
          
      Instrucciones que podés tipear
      
          
      
            Algunos ejemplos válidos (mayúsculas o minúsculas, según el simulador): sumas, copias entre ACC, GPR, M, MAR, PC, OPR, rotaciones ROL/ROR con F, y accesos con GPR(AD) / GPR(OP). Si empezás a escribir, aparece autocompletado con Tab o flechas.
          
      
          
      Inferencia
      
          
      
            Debajo del editor verás Instrucción y Modo en dos recuadros, cada uno con su icono. Se actualizan solos mientras editás.
          
      
          
      
            Las fórmulas usan notación de apuntes: ACC/4 significa dividir en entero, sin decimales.
            Si una rotación extrae un bit, se muestra como F y debajo se aclara de dónde sale.
            Si intervienen varios bits distintos, aparecen como F1, F2, etc.
          
      
          
      Reiniciar
      
          
      
            Reiniciar vuelve al estado inicial de registros y memoria.
          
      
          
      Generar microoperaciones
      
          
      
            Abajo podés escribir una operación de alto nivel (por ejemplo ACC <- ACC - F), elegir el modo de direccionamiento si aplica y pulsar Generar para rellenar el editor con la secuencia de microoperaciones.
          
      
          
      Traza y memoria
      
          
      
            En el menú lateral, Traza abre la vista dedicada: arriba cargás registros y RAM, abajo la tabla de ciclos (estilo exámen). Memoria muestra el mismo panel de registros y convive con el editor. En Editor seguís viendo código e inferencia a la izquierda y la traza a la derecha.
